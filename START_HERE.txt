                           🎯 UNDERSTANDING YOUR RESULTS

When the scraper finishes, you'll get an Excel file with your leads:

  🌟 TIER 1 = HIGH VALUE LEADS
     Companies with specialized roofing keywords (silicone coating, roof
     restoration, etc.) - These are your BEST prospects!

  🔧 TIER 2 = OPPORTUNITY LEADS
     Companies without websites - Great for offering digital services!

  📄 TIER 3 = STANDARD LEADS
     Companies with websites but no specialized keywords


The Excel file has columns for:
  • Company Name
  • Phone Number
  • Email (scraped from their website)
  • Website URL
  • Address
  • Which keywords were found
  • Which city/zip they're from


================================================================================

                              ❓ TROUBLESHOOTING

❌ "python is not recognized"
   → You didn't check "Add Python to PATH" during Python installation
   → Solution: Uninstall Python, reinstall it, CHECK THE BOX this time

❌ SETUP.bat shows errors
   → Make sure you installed Python first
   → Make sure you have internet connection
   → Try running SETUP.bat again

❌ Browser doesn't open
   → Run SETUP.bat again
   → Make sure you have Chrome or Chromium installed

❌ Taking too long / seems frozen
   → It's not frozen! The script runs SLOWLY on purpose (to avoid getting
     blocked by Google)
   → You'll see progress bars showing it's working
   → Full version genuinely takes 2-4 hours

❌ Not finding many Tier 1 leads
   → This is NORMAL! Most roofing companies don't use specialized coatings
   → That's why Tier 1 leads are so valuable - they're rare!
   → Even 20-30 Tier 1 leads is a great result
