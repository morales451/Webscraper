🛠️ COMMON CAUSES & SOLUTIONS
────────────────────────────────────────────────────────────────────────────

❌ CAUSE 1: Cookie Consent Dialog
──────────────────────────────────

SYMPTOM: You see "Accept all" or "Accept cookies" buttons on the page

SOLUTION: I've updated the scraper to handle this automatically!
  1. Make sure you have the latest version of the scripts
  2. Try running RUN_DEMO.bat again
  3. The script should now click through the cookie dialog


❌ CAUSE 2: CAPTCHA / Bot Detection
────────────────────────────────────

SYMPTOM: You see "I'm not a robot" or CAPTCHA challenges

WHY: Google detected automated traffic and is blocking you

SOLUTIONS (try in order):

  Option A: Wait and Try Again
    • Wait 2-4 hours
    • Google's block is usually temporary
    • Try during off-peak hours (late night/early morning)

  Option B: Use a Different Network
    • Switch from WiFi to mobile hotspot (or vice versa)
    • Try from a different location
    • Use a VPN (change your location)

  Option C: Clear Browser Data
    • The script uses Chromium browser
    • Close the script
    • Delete folder: C:\Users\YourName\AppData\Local\ms-playwright
    • Run: playwright install chromium
    • Try again

  Option D: Reduce Frequency
    • Only run the scraper once per day (max)
    • Running too often gets you blocked
    • Consider running only 1 city at a time


❌ CAUSE 3: Slow Internet Connection
─────────────────────────────────────

SYMPTOM: Pages load slowly in the browser window

SOLUTION:
  • Check your internet speed
  • Close other programs using bandwidth
  • Try at a different time when internet is faster
  • The updated script now waits longer (5 seconds instead of 3)


❌ CAUSE 4: Google Maps Changed Their Design
─────────────────────────────────────────────

SYMPTOM: The search box looks different or is in a different place

SOLUTION:
  • Run TEST_CONNECTION.bat and send me the screenshots
  • Google occasionally changes their layout
  • The script may need updates to work with the new design


❌ CAUSE 5: Antivirus/Firewall Blocking
────────────────────────────────────────

SYMPTOM: Browser opens but page won't load

SOLUTION:
  • Temporarily disable antivirus and try again
  • Add Python and Playwright to firewall exceptions
  • Some security software blocks automated browsers
